# Chapter & Co. — Book Tracker

A responsive personal reading journal built with plain HTML, CSS, and JavaScript.

## Features
- Dashboard overview with counts for all books, to-read, reading, and finished.
- Add books with required title and author.
- Update status, delete books, search title/author without case sensitivity.
- Filter by status; sort newest first, oldest first, or title A–Z.
- Reading statistics and responsive mobile layout.
- Browser `localStorage` persistence across refreshes.

## Run
Open `index.html` in a modern browser. No installation or build process is required.

## Publish using GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, `README.md`, and `PROMPTS.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for the published website URL to appear on the Pages settings page.

Books are stored only in the current browser on the current device; this project does not sync data to an account or server.
